\doxysubsection{Detailed Description}
An abstract base class for all pages that display database-\/driven content. 

This class serves as an interface to ensure that all sub-\/pages (like Admin, View Campuses, etc.) implement a standardized refresh mechanism to stay in sync with the SQLite database.
