\doxysubsection{Detailed Description}
The main entry point and UI controller for the College Tour application. 

This class manages the central QTab\+Widget, coordinates signal/\+slot connections between sub-\/pages (like \doxylink{class_admin_page}{Admin\+Page} and \doxylink{class_info_page}{Info\+Page}), and handles application-\/wide database maintenance tasks.
