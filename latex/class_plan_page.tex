\doxysubsection{Detailed Description}
Manages the multi-\/step trip planning process and the live tour interface. 

This class handles three distinct UI states via a QStacked\+Widget:\+
\begin{DoxyEnumerate}
\item {\bfseries{Settings (Index 0):\+}} Users select a starting campus and destination schools.
\item {\bfseries{Plan-\/\+Only (Index 1):\+}} A visual horizontal scroll view of the calculated path.
\item {\bfseries{Full-\/\+Trip (Index 2):\+}} An interactive "{}\+Stop-\/by-\/\+Stop"{} shopping interface.
\item {\bfseries{Results (Index 3):\+}} A summary of purchases and total distances for the trip. 
\end{DoxyEnumerate}
